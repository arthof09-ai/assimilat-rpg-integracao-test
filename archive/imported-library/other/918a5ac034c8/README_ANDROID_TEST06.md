# Arena TEST06 — uso rápido Android (MESTRE-ONLY)

Abra `TABLETOP_ASSIMILACAO_INOVADOR_TEST_06.html` num navegador compatível. É um arquivo local offline; telas e nomes de personagens são inteiramente TEST e não servem para Party.

1. Selecione **20×20** no seletor Tabuleiro, aumente zoom com **+**.
2. Ative **✋ Arrastar mapa** para navegar sem mover tokens. Desative e toque numa peça + casa azul para movimento sintético.
3. Toque no **minimapa** para ver outra região. Use **⌖ Focar selecionado** para localizar a peça escolhida.
4. Desligue e ligue as camadas Coordenadas, Ameaças TEST e Casas alcançáveis TEST; os resultados mecânicos não mudam.
5. Faça gesto de pinça com dois dedos e toque na célula depois; não deve ficar bloqueada.
6. Toque **Capturar histórico local**, avance e retroceda. Veja deslocamentos antes→depois; exporte/importar JSON TEST se o navegador permitir salvar arquivos locais.

**Registre:** modelo Android, navegador/versão, se abriu `file://`, zoom, pinch, pan, minimapa, replay, export/import, bugs e capturas. Não há homologação do dispositivo até execução pelo Mestre.
