## Objetivo

Comprovar que o conector GitHub do ChatGPT consegue ler e criar um arquivo novo em um repositório privado autorizado.

## Limites da experiência

- Arquivo administrativo e inteiramente sintético. Não contém fichas de personagens, dados da Party, motores oficiais nem segredos.
- Nenhum programa executado no GitHub; nenhuma alteração do Notion, dos demais laboratórios ou do cânone.
- Os próximos arquivos devem ser preparados e verificados antes de qualquer execução automatizada.
- Autorização de repositório não significa autorização para alterar os laboratórios de outros Comestres.

## Evidências

- Conta, repositório, visibilidade `private`, permissões de leitura/gravação e conteúdo inicial do README verificados via integração.
- A leitura de retorno deste arquivo deverá comprovar a persistência do teste de escrita.
